## 操作

左上角目录按钮 / `]` 收起或展开左侧目录；`[` 隐藏或显示右侧讲解。右上角月亮/太阳切换纯黑或亮色界面，原始PDF不反色。主题、目录状态与阅读位置保存在本机浏览器。

方向键 / J、K 翻页；输入页码直接跳转；F 切换适应页面/宽度；`/` 搜索课件正文及讲解；搜索 `@star` 查看收藏。

## 考核中心与“下个考点”

顶部和左侧目录均可打开**考核中心**，左侧收起时入口仍在。集中整理55条：明确考核8条、Quiz复盘10条、课堂重点22条、范围与选读5条、项目与安排10条。支持分类、搜索、查看录音出处和跳回对应PDF页。

“下个考点”严格取当前页之后、按课件顺序排列的下一个代表页。相同主题在同一份课件只取一个代表页；结束后禁用，**绝不回绕到第一讲**。按钮提前显示目标页。默认包括课堂重点，但课堂重点不等于必考；在考核中心取消相应选项后，只导航明确考核/Quiz复盘。

## 来源与边界

逐页注释依据原PDF画面以及对应课程已提供的教师录音转写（BMEB316 6份，AI301 7份）。来源按**内容**对应，不声称精确到翻页时刻；自动转写可能有错词，未获得原始音频进行声学校正。存在标签、公式或转写歧义时，注释说明不确定之处，不能将它升级成确定的考试承诺。

后续录音中复盘过的两个PPT-only部分的概念会出现在考核中心，但没有据此虚构整讲录音。考核中心整理的是已提供材料，不是持续更新的正式课表；暂定安排以教师/助教/Blackboard最终公告为准。Quiz只整理概念和错误原因，不发布完整试卷/选项。完整课堂转写和学生自我介绍未公开，网站仅保存与讲解对应的教师片段。

## 维护

`data/page-notes/*.json` 是逐页讲解的唯一内容来源；`data/sources.json` 是去重后的来源片段；`data/exam-guide.json` 是考核条目；`data/slide-index.json` 保存课件页码与搜索文本。`data/content.json` 由这四者合成。

运行 `python3 build_data.py` 重建并验证：PDF哈希未变、录音来源引用存在、395页讲解齐全且不重复、所有考核页锚有效。不能再用旧的范围模板 `guides.ndjson`；该输入已删除。
